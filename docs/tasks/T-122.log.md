### Finding F4
- **F4 (minor):** `pveum user token remove plumb@pve plumb` does not remove the token's ACLs on PVE 9.2.26. `user.cfg` keeps 7 `acl:` lines for `plumb@pve,plumb@pve!plumb`, and every `pveum`/`pvesh`/`qm`/`pct` call prints `user config - ignore invalid acl token 'plumb@pve!plumb'` (7 times) until the restore makes the token again. Effect: noise; the new token of `--restore` has the same name, so the old lines apply to it again at `token add`, before the installer's `acl modify` (the same rights, no more). Same on a plain `--remove` (line ~2072), not checked here.
