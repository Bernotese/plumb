# T-256 – Leak hunt, repo part (log)

Owner: pl-reviewer. Reviewer: pl-backend (the method); pl-lead reads the hit list. **This file has the method and the counts only. No value, and no place of a value: from a place a reader could infer the value (for example which example address is a test-host address). The place list is a 0600 file outside the repo, given to pl-lead.**

## Method

- **What:** every ref of `origin` (a scratch `git clone --mirror`: 64 heads and 387 `refs/pull/*`); the text of every issue, PR, review, review comment, issue comment and commit comment (`gh api`, each text in its own file named by its id); the logs of every Actions run that GitHub still keeps (one run at a time: download, scan, delete); the artifacts (none are kept); and the web bundle built from `main` (`npm ci && npm run build` in a scratch clone).
- **Pass 1, a secret scanner:** gitleaks v8.18.4, built from source with `go install …@v8.18.4` into the scratchpad, run with `--redact` (its report never holds a value); `detect --log-opts=--all` over the mirror, `detect --no-git` over the texts, each run's logs and the bundle.
- **Pass 2, the exact values:** `scripts/leak-scan.py`. It reads the values from the dev VM's files under `~/.config/plump/` **inside the process** (no value on a command line, in a log or in its output), and writes `place<TAB>kind` lines to a 0600 file:
  - the test-host addresses (the address keys of `testhost.env`; the node, pool, storage, VMID, file paths and the public image URLs/checksums are public in the repo and left out);
  - the admin password, the API token (also its secret part), the recovery key;
  - the guest SSH private key (each body line, except the first, which is the same for every unencrypted OpenSSH key), the guest public key, the host's Plumb CA certificate (each line);
  - from the old host logs and the install command: addresses, MACs, SSH host key fingerprints.

  Each address is marked private or public-internet, and as "also in AGENTS.md/README.md" when the current docs name it on purpose (the dev VM address). A value from several files names every source. Positive control: a scan of the value files themselves finds every kind (41 places).
- **On a hit:** report to pl-lead at once; no rewrite, no delete, no force-push (card).
