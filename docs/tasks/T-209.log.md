# T-209 log

## Sweep: per-Target state at a Target delete

| State | Dropped at delete | Why |
|---|---|---|
| `guest_host_key`, `repair_report` | **yes, now** (same tx as the binding; tied to `ref@gen`) | F10: a reused VMID or name inherited the pins |
| `agent`, `enroll_token` | yes (`Revoke` before `DeleteBinding`) | D-211; a parked agent keeps its row until unbind/forget (D-396) |
| `unbind_pending` | no, on purpose | D-396: the park outlives the Target; it blocks the name until unbind or forget |
| `foreign_guest` | yes (same tx) | D-322 |
| `binding` (waiting, root grow) | yes | the gen is never reused (0024) |
| open Issues (drift, guest:config, guest:address …) | **yes, now**: resolved gone by system, comment "Resolved: the Target was deleted." | no report can resolve them after the delete (D-211); a new Target of the name took them over |
| Issues a Plan is resolving | no | their Run decides |
| `agent:values` Issue + `guest_value_flag` | **no, on purpose** (until the flag ends) | D-397, pl-lead: the copy rule needs them; with any flag every value Plan is human-only |
| `guest_value` (hashes) | no, on purpose | copy-rule evidence (D-331); pruned 30 days after last seen now that the Issues end |
| `issue_ignore` | **yes, now** | "Ignore once" of the old guest must not swallow the new guest's first drift (D-091) |
| `ignored_drift` | **yes, now** | record of the old guest (D-092) |
| `run_step` | no | audit history |
| restore state (`revoked`, `unknownT`) | yes (`targetDeleted`) | D-325 |
| link `targets[name]` | reset by `Revoke` (entry stays) | harmless, reused in reset state |
| link drift buckets | n/a | keyed by agent id |
| engine `addrs` | at the next guest poll | harmless |

Known low, not changed: `ReopenGoneIssue` (D-215) can reopen a gone Issue of the old Target for `guest:address` within its window if a new Target of the name reports the same resource at once.
