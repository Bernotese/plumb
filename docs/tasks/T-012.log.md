## Run 1 – TestHostLifecycle: FAIL (driver bug)
`proxmox: VMID 9000 is not a template` right after FetchImage. Cause: `GET /pools?poolid=plumb` builds the member fields from the cluster resource cache; `template` stays 0 for a few seconds after the conversion (later the same call says 1). The test cleanup used the same flag and left template 9000; it was removed by hand with the token. Worse case without a test: a second FetchImage within those seconds would have removed the fresh template as "half-made".
