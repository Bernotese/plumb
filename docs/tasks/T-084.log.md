## Lesson (run 1)
A non-interactive repair run must keep stdin open under `ssh -tt`: `ssh -tt … "install.sh --yes …" < <(exec sleep N)`. With `</dev/null` the remote pty gets EOF and a later `pct exec` dies with SIGHUP (exit 129). A second run of the same command repairs it (the installer is idempotent).
