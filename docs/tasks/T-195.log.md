**R2 (survives, accepted):** the time check is a second guard behind R1. To kill it, an agent with a **new** id must say hello before the session started, so another enrollment must happen between the Run reading the old agent and the session start (for example an install command used at the same moment). `reserve` keeps other Runs of the Target out, but not an install command. The window is two statements wide. Not testable without a hook; kept as defense in depth.

**A3:** the owner check needs a file of another uid. The dev VM and the Go CI job do not run as root, and a root-owned file is either refused by the mode check first (0644) or cannot be opened (0600). So the new `internal/agent/guest_oneshot_qa_test.go` (tag `guest`, run as root by `test/guest/run.sh` with `^TestGuest`) checks it: a 0600 file of uid 65534 is refused with "not owned", the same file owned by root is read. The mutant can only be judged by the container job's log.
