## Findings

1. **P1: an agent refusal can persist a secret value.**
   `TestQASecretValuesAndErrors/refusal` sends the rendered env file through the real plan/link path.
   The fake agent refuses the apply and reports only the raw password in both `Report.Error` and item `Output`.
   The run fails, but `GET /api/v1/runs/{id}` and `plumb.db-wal` contain that password.
   `internal/link/link.go:478-486` remembers the whole sensitive attribute, such as `DB_PASSWORD=<value>\n`.
   Its masking therefore misses an error that quotes only `<value>`.
   This breaks D-089 and the no-value acceptance criterion. The test reports no log/event hit in this scenario.
   Fix in the owner branch. Keep the raw value out of every stored error/output, including command errors and item outputs.

2. **P2: nested and list references bypass parameter validation.**
   `TestQASecretNestedReferences/{nested,list}` passes an object parameter containing
   `{password: {secret: app-db}}` or `{passwords: [{secret: app-db}]}`.
   `Validate` accepts both. The top-level `opts` parameter has no `writeOnly` annotation.
   `internal/state/validate.go:599-608` checks only each top-level value with `refName`.
   D-088/D-137 permit references only for a top-level secret string parameter.
   These nested maps remain ordinary template data; this test does not demonstrate secret-value disclosure.
   Reject them with the pointer of the nested reference, or obtain an explicit decision allowing literal nested reference-shaped maps.

3. **P2: a validation answer contains reserved marker characters.**
   `TestQASecretMarkerErrorResponse` adds a parameter key `U+E000 forged U+E001`.
   The proposal correctly returns 422 `validation`, but its error pointer contains those same characters.
   `internal/api/handlers.go:60-66` serializes the validation pointer unchanged.
   This breaks the explicit criterion that no API response contains U+E000/U+E001.
   The test does not demonstrate secret-value disclosure. Preserve a useful pointer without sending the reserved characters.
