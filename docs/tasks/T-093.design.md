# T-093 – attribute proposal (pl-reviewer → pl-architect, input for T-090 schemas)

The T-090 schema wins. This is what the T-093 code expects now.

## apt_repository  (key: name; vm, lxc)
- `name`: `^[a-z0-9][a-z0-9_.-]*$` (max 64). Files: `/etc/apt/sources.list.d/plumb-<name>.sources`, key `/etc/apt/keyrings/plumb-<name>.asc`.
- `uris` (array of string, `^https?://`, min 1), `suites` (array, min 1), `components` (array, default []; empty only if one suite ends in `/`), `architectures` (array, default []).
- `key` (string, required when present): ASCII-armored public key. Agent refuses a private key block and anything that is not one armored public key block.
- `state` present|absent.
- No free `options`: Plumb writes `Signed-By: <key file>` itself; `Trusted`, `trusted.gpg.d` cannot be expressed.
- Risks: create/change reversible; delete reversible (packages stay). Apply runs `apt-get update` under the package lock.
## unit  (key: name; vm, lxc)
- `name`: must end in a unit suffix (.service .timer .socket .path .mount .automount .target .slice .swap); `plumb-agent.*` refused (save check + agent).
- `content` (string, required when present), `state` present|absent. File `/etc/systemd/system/<name>`, mode 0644 root:root.
- Only file + `daemon-reload`. Enable/start (also of a timer) stays with `service` (name `x.timer`, `restart_on: [unit:x.service]`).
- Risks: create/change reversible; delete destructive.
## sysctl  (key: name; vm only)
- `name`: `^[a-z0-9_]+(\.[a-zA-Z0-9_-]+)+$` (no `/`, no `..`), `value` (string; whitespace runs compare as one space), `state` present|absent.
- Persist: `/etc/sysctl.d/60-plumb-<name>.conf`; runtime: `/proc/sys/<name with . → />`.
- Risks: change disruptive (kernel settings can cut the network); absent = file removed, runtime kept, reversible.
