- D-274 · 2026-11-12 · accepted (pl-reviewer, T-093) · A `unit` or `service` resource is refused for every unit name that starts with `plumb-agent` (`plumb-agent.timer`, `plumb-agent-install.service`, `plumb-agent-guard.timer`, `plumb-agent@x.service`, …): a prefix rule, not a list, so units that a newer agent adds are covered and a timer, path or socket cannot start the agent's service. `wire.IsAgentUnit` is the one rule, at save (`wire.AgentConflicts`), in the schema of `unit` and in the agent.
