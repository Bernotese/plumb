- D-249 · 2026-11-12 · pl-backend, T-079. Proxmox keeps no copy of a container's `ssh-public-keys`, so the proxmox driver writes one description line `plumb-ssh-key: <key>` per key at create (as the image marker, D-189) and Observe reads `ssh_keys` from them. The description holds 8192 bytes (PVE 9.2 `maxLength`): validation refuses an LXC Target whose key lines take more than 7168 bytes or whose key starts or ends with white space or holds a control character (so a line comes back byte-equal; review S1 of #162), and Create refuses the same and a description over 8192. A person who edits or removes a line makes `ssh_keys` differ: a `guest:config` drift Issue, and a Plan for the Target is refused with "create a new target instead"; Plumb never re-creates the container for it · a hash of the key set cannot work: the engine compares the key lists themselves (`DriftGuest`); public keys are no secret
- D-250 · 2026-11-12 · pl-backend, T-079 PR C. (a) Outside additions of a container: `guest:config` reads `features`, mount points (`mounts`), devices (`devices`) and raw `lxc.*` lines (`raw_lxc`); Plumb sets only `features: nesting=1` (D-227), so any other value is drift with risk `destructive`. "Revert" writes only `features` back (active at the next start; waiting for it is no drift); for mount points, devices and raw lines Diff returns an `OutsideError` and a Plan is refused with a text that names every addition of both views (pending ones marked) with its value quoted, the exact `pct set <id> --delete mp0,dev1` and, for raw lines, the file `/etc/pve/lxc/<id>.conf` and the lines, because only root can remove them (host H10); a pending addition keeps the risk `destructive`; "Accept" is refused for all four; "Ignore" works. (b) Create writes the description line `plumb-template: <volid>`, and `ListImages` returns the Image's `vztmpl` files (kind `template_file`) with the number of pool containers that name each file; `TemplateRef(spec)` gives the file of the current Image without a host call (T-085). A wrong or removed `plumb-template` line only changes the "unused" list: Plumb never deletes a `vztmpl` file (D-233) · Proxmox keeps no `ostemplate` in a container config; the token cannot remove host mounts or devices, so offering a revert for them would always fail
