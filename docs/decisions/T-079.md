- D-249 · 2026-11-12 · pl-backend, T-079. Proxmox keeps no copy of a container's `ssh-public-keys`, so the proxmox driver writes one description line `plumb-ssh-key: <key>` per key at create (as the image marker, D-189) and Observe reads `ssh_keys` from them. The description holds 8192 bytes (PVE 9.2 `maxLength`): validation refuses an LXC Target whose key lines take more than 7168 bytes, and Create refuses a description over 8192. A person who edits or removes a line makes `ssh_keys` differ: a `guest:config` drift Issue, and a Plan for the Target is refused with "create a new target instead"; Plumb never re-creates the container for it · a hash of the key set cannot work: the engine compares the key lists themselves (`DriftGuest`); public keys are no secret
