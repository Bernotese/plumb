One exception to the cover rule of D-075 (`resource.NewUnitCovers`): a Plan that observed a service as absent (`state: absent → S`, `enabled: null → E`) also covers `state: stopped → S` and `enabled: false → E` (same to, same risk) when an earlier step of the same apply that the service waits for (after, restart_on, or earlier in its Block use) created the unit: the `unit` of the same name, the file `/etc/systemd/system/<unit>`, or a `package`. Every other change still needs `wire.Covers`; a unit that appeared outside the apply, a masked unit, another to or risk, or an unplanned restart is refused.
