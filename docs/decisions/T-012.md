- D-187 · 2026-11-11 · `Create` always sets `nameserver` and `searchdomain` on a new VM, for static and DHCP guests alike. The values are two new controller settings: `PLUMB_PVE_NAMESERVER` (1 to 3 IP addresses, comma-separated; the driver joins them with a space) and `PLUMB_PVE_SEARCHDOMAIN` (one DNS name). Both are required (D-182). `install.sh` writes them from the DNS settings of the host at install time (`nameserver` and `search` of `/etc/resolv.conf`; without `search` the domain of the host name; without both it stops with a message). They go to `proxmox.Config`, and `New` refuses an empty or bad value. Both are cloud-init inputs, so they are create-only (D-185 A): a change of the settings reaches only new VMs, and the driver never writes them to an existing guest.
