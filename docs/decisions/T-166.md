An observed attribute whose reported value is a status text and not the guest's value is opaque (`resource.Type.Opaque`: `firewall.table`, `network.file`, `apt_repository.sources`, `sysctl.file`). A drift report with an opaque change stores one keyed hash for the whole resource type (the text `\0plumb-opaque\0<type>`), with the retention of every guest-value row (kept while its Issue is open, then 30 days after the last report; ignore once and rules do not end it). While it counts, a Plan that adds or changes a value of any non-key attribute of a resource of that type, on any Target, is human-only (`accept-guest-data`): new list and string elements, and every changed enum, boolean or number as a whole (`policy`, `ping`, `ssh_port`, `allow_no_ssh`, an integer sysctl `value`; review O1 of #264); `guest_data_matches` names each new element of the Plan (never the guest's text). Removals stay free (dropped list elements, `state: absent`). Text attributes marked `x-plumb-lines` (`file.content`, `unit.content`) also hash each line that the desired text does not have, on the report and on the Plan (lines of at least 8 non-space characters; the MaxGuestElems bound counts only the new lines, past it the Target is flagged or the Plan is human-only; review O2 of #264). A line is compared after collapsing spaces and tabs to one space and lower case (review W1 of #264). Known limit: the line rule catches only verbatim or normalized copies; an edited, split or commented line is not caught. The opaque-type rule is the fail-closed part; the line rule only narrows the gap of whole-text values. Every resource type is either a value type or names its opaque attributes; a test fails for an unclassified type · the agent cannot always map a hand change (any nft rule, any netplan or sources text) to the attribute model, and an old agent reports only the status text: the server-side rule fails closed for both, needs no agent change and no version gate; the price is that, after a hand change, token Plans that add values of that type need a person for 30 days
