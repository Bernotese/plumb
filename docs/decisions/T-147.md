- D-351 · 2026-11-13 · accepted (pl-reviewer, T-147; pl-lead; refines D-311). A restore (`plumb restore`) makes the user `admin` an enabled admin again (`role = admin`, `disabled_at` cleared) together with its new one-time password, also when the backup had it demoted or disabled; every other user stays locked (D-303). So the restored controller has exactly one admin who can log in, and the last-admin rule (D-330) holds at once. A database without a user `admin` (names cannot change, but a backup may lack it) fails the restore in its transaction and changes nothing · without this, a backup taken after `admin` was demoted would give a controller on which nobody can manage users
